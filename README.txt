# Shot and Framed — Zackery Lau Photography

A free, custom photography portfolio website built with plain HTML, CSS, and JavaScript.

## Open it
Double-click `index.html` to preview it in your browser.

## Put it online for free
The easiest option is GitHub Pages:
1. Create a free GitHub account at https://github.com/
2. Create a new repository named `yourusername.github.io`
3. Upload everything in this folder.
4. In the repository settings, enable Pages if it isn't already enabled.
5. Your site will be available at `https://yourusername.github.io/`.

## Add your contact information
Open `script.js` and edit:
- `email: ""`
- `instagram: ""`

You can fill in either one or both.

## Add more photographs
1. Put a web-ready JPG in `images/`.
2. Copy one of the `<figure class="photo ...">` blocks in `index.html`.
3. Change the image path, title, alt text, and category.

## RAW / CR3 files
The CR3 files you uploaded are not included because browsers do not display Canon RAW files directly. Export them from Lightroom, Canon Digital Photo Professional, Photoshop, or another RAW editor as JPEGs and add them to the `images/` folder.
